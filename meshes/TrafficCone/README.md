# Traffic Cone

A comparison scene demonstrating `KHR_materials_retroreflection`.

`TrafficCone.gltf`, its buffer, and its textures are unchanged copies from [Khronos glTF Sample Assets at revision f36bfdabd1031c3cf6689a50570b8cdf3678b49c](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/f36bfdabd1031c3cf6689a50570b8cdf3678b49c/Models/TrafficCone). The upstream scene adapts the original cone to demonstrate retroreflection.
